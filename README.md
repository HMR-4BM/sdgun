# SDGun 二手交易市场工具

一个仅使用 Python 标准库实现的 SDGun 公开二手交易帖增量采集、检索与市场分析工具，
同时提供命令行爬虫和本地 Web 控制台。

> 本项目仅用于读取无需登录即可访问的公开信息。使用者应遵守目标站点条款、控制请求频率，
> 并自行确认其使用方式符合当地法律法规。

## 主要功能

- 增量扫描与持续监控：使用 SQLite 游标续接，避免反复请求已扫描页面。
- 精准过滤：先检查页面标题，再解析目标帖子和评论，减少无效请求。
- 本地市场面板：展示供需、价格、交易状态、热门物品词和活跃发布者。
- 多关键词检索：支持任意词/全部词、字段范围、否定语境识别和结果高亮。
- 数据归档与导出：按月归档 SQLite 数据，并支持 CSV、JSONL 导出。
- 零第三方依赖：Python 3.9+ 即可运行，无需安装额外包。

## 项目结构

```text
.
├── sdgun_crawler.py       # 命令行爬虫、解析器与 SQLite 存储
├── web_app.py             # 本地 Web 服务与数据 API
├── web/                   # Web 控制台静态资源
├── start_web.bat          # Windows 一键启动脚本
├── test_sdgun_crawler.py  # 爬虫与解析逻辑测试
└── test_web_app.py        # Web、检索与归档逻辑测试
```

程序运行后生成的 `*.db`、`data/`、导出文件和缓存属于本地数据，默认不会提交到 Git。

面向按数字 `tid` 排列的帖子页。程序先检查 `<title>`，仅当标题以
`【二手出售】` 开头时才解析帖子 JSON 和请求评论，因此非目标页不会进入正文、图片、
评论或趋势处理。

## 快速使用

Python 3.9+，无第三方依赖：

```powershell
# 可选：先确认环境和运行测试
python --version
python -m unittest discover -v

# 启动本地 Web 控制台
python web_app.py

# 倒序扫描一段新 tid；结果写入 SQLite，命中帖同时输出到终端
python sdgun_crawler.py scan --start 4010000 --end 4009000 --workers 16

# 只保留包含任一关键词的帖子，并导出本次命中
python sdgun_crawler.py scan --start 4010000 --end 4009000 -k 锦明 -k 波箱 --jsonl latest.jsonl

# 已扫描过的 tid 默认跳过；需要重新检查（例如刷新“已出”状态）
python sdgun_crawler.py scan --start 4010000 --end 4009000 --no-new-only

# 从数据库生成分类、热门物品词和最新帖子摘要
python sdgun_crawler.py report --limit 1000 --top 30

# 从已知最新帖子之后持续监控；后续启动自动从数据库游标续接
python sdgun_crawler.py watch --start 4148800
```

查看完整命令参数：

```powershell
python sdgun_crawler.py --help
python sdgun_crawler.py scan --help
python sdgun_crawler.py watch --help
python web_app.py --help
```

## Web 可视化控制台

双击 `start_web.bat`，或运行：

```powershell
python web_app.py
```

然后打开 `http://127.0.0.1:8765`。控制台提供市场总览、供需趋势、交易状态、
价格带、热门物品词、活跃发布者、最新帖子、详情查看、多关键词检索、增量同步、
任务停止以及 CSV/JSONL 导出。

搜索框支持使用空格、逗号、顿号或分号分隔多个关键词；可选择“部分命中”（任意词）或
“全部命中”（每个词都必须出现），并可把检索范围限定为全部内容、仅标题或仅作者。
检索结果提供“快速定位”：打开帖子后会在标题、作者、正文、物品明细和评论中高亮关键词，
并自动滚动到第一个命中位置。
“全部内容”检索不会读取图片地址、帖子链接或闲鱼链接中的文字。类似“不含手电／不带手电／
没有手电”的否定语境仍保留在结果末尾，但使用灰色删除线和“排除”标记，不算作正常命中。

“市场猎手”以点击启动的时间为追踪起点，启动前的帖子只用于建立历史基线，不显示、
不计入命中、也不提醒。它可保存一组同样的关键词、命中方式、检索范围和交易状态规则，
按自定义间隔自动增量刷新并检索。新帖命中时同时更新结果列表、显示页面提醒，并在用户授权后发送浏览器
系统通知；最短间隔为 10 秒，停止猎手不会影响普通刷新和数据库内容。

帖子默认按照论坛的实际 `created_at` 倒序排列，不使用爬取时间排序。系统持久保存
`last_recorded_id`；每次打开页面或点击“刷新最新”，先调用玩具交易区（fid 176）的
公开帖子列表，直接取得当前已经发布的最大 TID，再从 `last_recorded_id + 1` 采集到该
TID 后立即停止。不会再用当前时间等待新帖，也不会探测未来编号。如果旧版游标已经越过
真实边界，会自动回退并清理错误的未来扫描状态。没有需要填写的起止区间，也不会重复扫描
历史编号。同时重新读取最近 10 个交易帖、每帖最多 5 页评论和状态，因此
后来出现的“已出”也会更新。新发现且发布时间晚于本次打开时间的帖子会显示 `NEW`。

### 每日盘数据

系统以 `Asia/Taipei` 自然日（00:00:00–23:59:59）为一个盘，并将结果持久保存到
SQLite 的 `daily_market` 表。每盘量化保存：首末 TID、首末发帖时间、总发帖量、
出售/已出/求购/待确认数量、公开售出率、活跃用户、物品条目、价格样本数、均价、
中位数、最低价、最高价、标价合计、评论、图片、闲鱼链接、热门物品词、活跃发布者、
发帖量日环比和中位价日环比。面板可直接查看，并通过“导出日盘 CSV”下载完整日线。

帖子同时按实际发帖时间归档到 `data/YYYY/MM/market.db`，磁盘文件夹最小分到月份；
月库内部使用 `post_day` 区分具体日期并建立日期索引。根目录数据库保留全局游标、扫描状态
和面板运行索引，月库用于按年月归档管理，不为每天创建零碎数据库文件。

首次使用时应把区间改成当前实际的七位数 `tid`。建议倒序扫描，`--end` 小于
`--start`。稳定后按上次最高 `tid` 向上扫描即可。默认 16 并发、6 秒超时、不重试；
网络不稳定时加 `--retries 1`，服务器出现限流时降低 `--workers`。

长期运行推荐 `watch`。它每轮并发探测一小段全站新 `tid`，只有检测到更高编号已经
存在时才把中间空号视为历史缺口；位于最前端、尚未发布的编号不会写成永久已扫描，
下一轮仍会检查。按 `Ctrl+C` 会保存 `watch_cursor`，再次运行无需提供 `--start`。
可用 `--poll 30 --batch 16 --workers 8` 调低站点压力；`--cycles 1` 可做单轮测试。

## 输出字段

每个命中帖包含：`tid/url/title/username/user_id/created_at/content/images/links/`
`xianyu_links/comments/category/is_sold/items/item_details/prices`。其中：

- `images` 只来自帖子内嵌正文和 `row.pics`，不扫描整页 `<img>`，不会混入头像、广告、等级图标；程序只保存图片 URL，不下载或识别图片。
- 评论分页接口只对标题与关键词均命中的帖子调用；评论正文中的闲鱼、淘宝短链等会进入 `links`，已识别的闲鱼链接同时进入 `xianyu_links`。
- `item_details` 按空行、编号/项目符号和“一行一件明盘价”拆分，每件物品分别保存状态与价格。
  多物品帖只有部分物品售出时，帖子状态为 `部分已出`；无物品指向的笼统“已出”评论不会把整帖全部标成已出。
- 同一帖子同时含出售与求购物品时标记为 `出售+求购`，帖子列表会在标题下分别列出两类物品。
- 价格只有带 `￥/¥/元/块/包邮` 等价格语境时才提取，不把日期、型号或数量误判为价格。
- SQLite 的 `scan_state` 保存所有访问结果，`posts` 只保存目标帖子；WAL 模式支持高吞吐写入。

## 效率策略

1. 单次下载帖子 HTML，先用极轻量正则检查标题；不匹配就立即返回。
2. 关键词在原始页面中先过滤，失败时不解析大型 JSON、不清洗正文、不请求评论。
3. 仅目标帖调用评论接口，单页默认取 50 条；Web 刷新只复查最近 10 帖且最多 5 页评论。
4. 规则分类与趋势词频均在本地完成，不调用大模型或图片识别。
5. `--new-only` 默认开启，避免重复请求已经扫描过的无关 tid。
6. 帖子列表不预载缩略图；打开详情时才懒加载帖子图片，点击复用同一图片在页面内放大。

## 访问边界与 robots 检查

2026-07-20 实测访问 `http://app.sdgun.com.cn/robots.txt`，站点返回
`{"success":false,"msg":"module not exists:robots.txt","code":0}`，即当前没有可读取的
robots.txt 规则文件。这不等于站点授予无限制抓取许可，仍应控制并发并留意站点规则变化。

本工具只读取无需登录即可访问的公开帖子页及其公开评论接口，不包含登录、Cookie 注入、
验证码处理或访问控制绕过。请控制并发并遵守站点条款及当地法律。
